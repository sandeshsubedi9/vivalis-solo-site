# Vivalis Solo Site

This is the source code for the Vivalis official website.

## Directory Structure

- `public_html/`: Contains the static HTML, CSS, and image assets for the website.
  - `index.html`: Homepage.
  - `css/`: Stylesheets.
  - `Images/`: Product and branding images.
  - Legal pages: `privacy-policy.html`, `terms-of-use.html`, etc.

## Technologies Used

- HTML5
- CSS3 (Vanilla)
- SEO Optimized (Meta tags, JSON-LD, Sitemap)

## Deployment

This is a static website and can be deployed to any static hosting service like GitHub Pages, Netlify, or Vercel by pointing to the `public_html` directory.
